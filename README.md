# Agentic CareerPilot 🚀

An evolving collection of Agentic AI experiments, practical assignments, and project development work, with a focus on building intelligent applications and exploring real-world AI solutions.

## 📌 About the Repository

**Agentic-CareerPilot** is a consolidated repository containing Agentic AI coursework, practical implementations, project source code, and technical documentation.

The repository currently includes two major components:

### 1. Agentic AI Assignments
A collection of 14 lab assignments exploring Agentic AI concepts and implementations.

**Contents:**
- Lab 1 – Lab 14
- Python-based implementations
- Practical exercises and experimentation

Location: `Assignments/Agentic/`

### 2. Placement Portal – CareerPilot
An AI-powered placement management portal designed to support students in their career preparation journey.

**Technology Stack:**
- **Frontend:** React, TypeScript, Vite
- **Backend:** Python, FastAPI
- **Infrastructure:** Docker, Docker Compose, Nginx
- **AI/ML:** Agent-based architecture and intelligent recommendation components

**Key Modules:**
- Resume Analysis
- Interview Preparation
- Coding Practice
- Skill Gap Analysis
- Job Search
- Company Information
- Agentic AI Lab

Location: `placement_portal/`

## ⚙️ Getting Started

### Clone the Repository

```bash
git clone https://github.com/AadyaKulkarni/Agentic-CareerPilot.git
cd Agentic-CareerPilot
```

### Explore the Assignments

Navigate to:

```bash
cd Assignments/Agentic
```

Run an individual assignment:

```bash
python Lab1-Assignment.py
```

### Run the Placement Portal

Navigate to the project directory:

```bash
cd placement_portal
```

Refer to `placement_portal/README.md` for environment configuration, dependencies, and application setup instructions.
